rdf-array test vocabulary

Namespace https://rdf-array.github.io/rdf-array/vocab#, also as Turtle. The rdf-array test suites use these terms with mf:requires, so that a runner can skip what an implementation does not have, and to mark the tests that use the array syntax proposed today. See the rdf-array documents.

TermKindMeaning
ra:SequencesfeatureThe sequence term: a syntax reads and writes ( e1 e2 … ) as one term, () the empty sequence.
ra:SequencePatternsfeatureSPARQL-array: a sequence term in a triple pattern, template or INSERT/DELETE DATA, with variables bound element by element.
ra:SequenceResultsfeatureSPARQL results carrying sequence terms: JSON {"type": "seq", "value": [ … ]}, XML <seq>, CSV and TSV spellings.
ra:GapPatternsfeatureSPARQL-array: `...` in a sequence pattern matches any run of members, and `...?rest` binds that run. Proposed syntax (docs/array-syntax.md).
ra:UnnestfeatureSPARQL-array: UNNEST(expr AS ?x AT ?i), one solution per member of a sequence, with its 1-based position. Proposed syntax (docs/array-syntax.md).
ra:SequenceFunctionsfeatureSPARQL-array functions isSEQ, SEQLEN and SEQ, the index expr[i], the slice expr[m...n] and `?x IN ?seq`. Proposed syntax (docs/array-syntax.md).
ra:ListShapeExpressionfeatureShEx-array LIST shape expression: LIST ( regex ) over the members, LIST * x, LIST + x, LIST {m,n} x; ShExJ {"type": "ListShape"}, ShExR sx:ListShape. Proposed syntax (docs/array-syntax.md).
ra:ShaclListConstraintsfeatureSHACL-array: SHACL 1.2's sh:memberShape, sh:minListLength, sh:maxListLength and sh:uniqueMembers over sequence values (a SHACL list is a sequence term).
ra:JsonLdArrayToRdfTestclassA JSON-LD-array test: plain JSON (input) and a mapping document (ra:mapping) to N-Quads-array (expect) or an error code (expectErrorCode).
ra:mappingpropertyThe JSON-LD-array mapping document of a ra:JsonLdArrayToRdfTest.

OWL-array vocabulary

The built-in entities of OWL-array, in the same namespace; their meaning is fixed by its semantics (§3), and owl-array.ttl is the OWL 2 DL ontology that declares them, with the axioms that hold of every sequence, for ontologies to import.

TermKindMeaning
ra:Sequenceclass, built-inThe sequences, the denotations of ( … ) terms, and nothing else.
ra:EmptySequenceclassThe empty sequence, (): ra:Sequence and ra:length value 0.
ra:ObjectSequenceclassA sequence with no literal element: ra:Sequence and not (ra:memberValue some rdfs:Literal).
ra:DataSequenceclassA sequence with no individual element: ra:Sequence and not (ra:member some owl:Thing).
ra:memberobject property, built-inEach element of a sequence that is an individual or a sequence. Counts distinct individuals, not positions.
ra:memberValuedata property, built-inEach element of a sequence that is a literal.
ra:lengthfunctional data property, built-inThe number of elements, an xsd:nonNegativeInteger.
ra:firstfunctional object property, built-inThe first element, when it is an individual or a sequence; a sub-property of ra:member.
ra:lastfunctional object property, built-inThe last element, when it is an individual or a sequence; a sub-property of ra:member.
ra:firstValuefunctional data property, built-inThe first element, when it is a literal; a sub-property of ra:memberValue.
ra:lastValuefunctional data property, built-inThe last element, when it is a literal; a sub-property of ra:memberValue.
